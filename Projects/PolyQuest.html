Poly Quest (Work in Progress)

Unity Crossplay Multiplayer ARPG Fishnet

Crossplay Multiplayer ARPG (Unity)

Poly Quest is a private solo project and a current prototype: an Action-RPG built in Unity that lets players jump into the same session from PC or mobile. Networking runs on Fishnet, synchronizing combat, movement, and world state across every connected client regardless of platform.

The project covers a lobby-based main menu with character selection, an ARPG character controller tuned for both mobile touch and PC input, and an inventory system that automatically persists to JSON.

Tools & Technologies

Unity
Fishnet
Blender

Crossplay Multiplayer Setup (PC & Mobile) with Fishnet.

ARPG Character controller with mobile and PC controls.

Inventory System with automatic saving in Json Format.

Main Menu with Lobby System and Character Selection.
